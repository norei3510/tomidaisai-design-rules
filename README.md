# 富大祭 共通デザインルール

共通デザインの仕様とCSSトークンを管理するpublicリポジトリです。初版は **v0.1.0** です。

1. [基本ルール](rules/foundations.md)：配色・文字・余白・角丸・操作状態。
2. [共通ヘッダーとナビ](rules/shared-shell.md)：ページ間で共有する枠とURL。
3. [CSSトークン](tokens/tokens.css)：フレームワークに依存しない変数定義。
4. [更新履歴](CHANGELOG.md)：変更理由と適用状況。

## 基準と適用状況

2026-10-21時点の来場者企画の現行CSSを基準にしています。現在のCSSトークンを古い説明資料より優先します。出典は来場者企画の `front/src/design-tokens.css` と `front/src/shell.css` です。

当日サイトは、初期移植でeventの見た目を維持しています。このルールはまだ当日サイトへ適用していません。ヘッダーとボトムナビの部品実装は後続の作業です。

## 取り込みと更新

利用側はタグ `v0.1.0` など、参照する版を固定してCSSを取り込みます。実行時にGitHubからCSSを取得する必要はありません。トークンの変更元は本リポジトリに揃え、各サイトへの適用は個別に検証します。

ゲーム固有の文章・正解・進捗処理・画像・企画データ・元Excelは管理しません。CSS変数の追加には用途を記載し、値の変更時には更新履歴を更新します。
