# トミー君の吹き出し

来場者企画で、案内役のトミー君がセリフを話す部品。

## 共通ページで使う条件
- 来場者企画への入口や、来場者企画と関係する案内だけで使う
- 1ページに1か所。ページの主な情報（日時・場所・操作）を吹き出しの中だけに書かない
- 画像（トミー君）は利用側が渡す。本リポジトリには置かない
- 使ったページは `pages/<ページ名>.md` に理由を書く

## 構造
アバター（左）＋吹き出し（右）の横並び、下端そろえ、間 `space-3`。

| 項目 | 値 |
|---|---|
| アバター | 64px（来場者企画の問題画面では79px、狭い高さで56px・40px） |
| 吹き出し | 背景 `color-bg-surface`、`radius-card`、`shadow-1`、内側 `space-4`（狭い所は `space-3`） |
| セリフ | `font-body` `leading-body`、`overflow-wrap: anywhere`、改行を保つ（`white-space: pre-wrap`） |
| 話者名 | ピル（`radius-pill`）、背景 `color-bg-header`、文字 `color-text-on-fill` `font-body` `weight-bold`、上下2px・左右 `space-3` |
| セリフ送り | 「前へ」は小さい枠線ボタン（高さ24px＋当たり判定を広げる）、件数は右に `font-xs` |

- セリフを送っても吹き出しの高さが変わらないよう、一番長いセリフの高さを確保する
- 吹き出しのしっぽは付けない（現行実装で非表示）
