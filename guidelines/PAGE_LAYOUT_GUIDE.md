# PAGE_LAYOUT_GUIDE — ページをどう組むか

> 答える問い: **ページの骨格をどう組むか。どこに何を置くか。**
> 骨格のHTMLは `layout_patterns/`。選び方は `layout_patterns/layout-index.md`。

## 1. 全ページ共通の骨格

```
┌──────────────────────┐
│ 共通ヘッダー           │ header-height ＋ 上セーフエリア。bg-header。ロゴ左、ページ固有の要素を右
├──────────────────────┤
│ 通知バー（あるときだけ） │
├──────────────────────┤
│                      │
│ 本文（縦スクロール）     │ 左右 space-4。1カラムは content-max で中央寄せ
│                      │
├──────────────────────┤
│ ボトムナビ             │ nav-height ＋ 下セーフエリア。5項目。白
└──────────────────────┘
```

- ヘッダーとナビは画面に固定し、本文だけをスクロールさせる。本文側に同じ高さの余白を確保する（または grid の行として並べる）
- ヘッダー・ナビの背景は全幅、中身は本文と同じ幅にそろえる
- 構造: `<header>` → `<main>` → `<nav aria-label="サイト">`。`<main>` の最初に `h1` を1つ

## 2. 本文の並び順

1. **いまどこか**: h1（ページ名、`3xl` の display 書体）。説明が要るときは件数・日時など具体的な値を1行（例: 「124件・10月24日（土）〜25日（日）」）。英字のアイブロウは置かない
2. **主な内容**: 一覧・表・地図・詳細・フォーム
3. **主な操作**: primary ボタン1つ。長いページでは内容の直後に置き、ページ末尾まで探させない
4. **補足**: 注意事項・関連リンク（アコーディオンで折りたたんでよい）

- 主な操作が最初の画面（390×844 でヘッダー・ナビを除いた範囲）に入らないページは、内容を削るか、要約を上に置く
- カードは白い面の中にさらにカードを入れない（入れ子は `bg-surface-soft` の面で区切る）
- 兄弟の要素を `position: absolute` や負のマージンで重ねない。重ねてよいのはバッジなど装飾だけ

## 3. 画面幅ごとの組み替え

| 幅 | 組み方 |
|---|---|
| 〜374px | 1カラム。カルーセルの画像幅を縮める。横スクロールを出さない |
| 375〜767px | 1カラム（基準） |
| 768〜1023px | 一覧は2列、詳細は1カラムのまま `content-max` |
| 1024px〜 | 一覧は2列のまま `content-wide-max`。ボトムナビはそのまま（サイドバーにしない）【暫定】 |

- 全体を拡大・縮小せず、並べ方を変える
- ナビとヘッダーの位置は画面幅で変えない

## 4. 高さが足りないとき

- 来場者企画は高さが 600px・440px・380px 以下で段階的に要素を省く。共通ページは縦スクロールで対応し、要素は省かない
- キーボードが出たとき、入力欄と送信ボタンが見える位置にスクロールする（`scrollIntoView({ block: "center" })`）。`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, interactive-widget=resizes-content">`

## 5. ページ間の移動

- サイト内の移動は通常のリンク（ページ遷移）。ボトムナビのリンク先は `components/base/bottom-nav.md`
- 戻る操作はブラウザの戻るに任せ、画面内に「戻る」を作る場合は前の階層へ戻す（トップへ飛ばさない）
- 一覧から詳細へ行って戻ったとき、一覧のスクロール位置を保つ

## 6. 当日ページ（1ページ1コンテンツ）

TOP・企画一覧・タイムテーブル・マップは、それぞれ1つのコンテンツだけを載せるページにする。

| ページ | 主役（最初の画面に出すもの） | 骨格 |
|---|---|---|
| 当日TOP | 現在時刻と「いま開催中」「次に始まる」 | `layout_patterns/top.html` |
| 企画一覧 | 場所コードごとの企画の索引 | `layout_patterns/list.html` |
| タイムテーブル | 時刻×ステージの表と現在時刻の線 | `layout_patterns/timetable.html` |
| マップ | 地図（幅いっぱい・比率を保つ）と場所コードの札 | `layout_patterns/map.html` |

- 最初の画面（390×844 でヘッダー・ナビを除いた範囲）に主役が入る。紹介文・ヒーロー画像・キャッチコピーを主役より上に置かない
- 別のコンテンツへは、ページの最後かボトムナビで移動させる。1ページに別のコンテンツの要約を並べない（TOP の入口の札は例外）
- 場所は全ページで同じ場所コード（`components/base/place-code.md`）で示し、一覧・表・地図を行き来しても同じ札で探せるようにする
- **タイムテーブル**: 767px 以下は、選んだステージの演目を時刻順の行（1行44px 以上）で並べ、現在時刻は行の間の区切り線で示す。時刻×ステージの格子の表は 768px 以上だけ。格子では短い演目の高さが 44px に届かないため【暫定】
- **マップ**: 構内図はスマホの幅では小さく、建物を地図の上で押し分けられない。建物を選ぶ主な手段は地図の下の場所コードの札にする。地図は［地図を拡大する］で画面いっぱいのダイアログに開き、指で拡大・移動できるようにする（viewport で拡大を禁止しない）
- 「いま」が変わるページ（TOP・タイムテーブル）は、ページを開いたときと1分ごとに現在時刻を更新する。開催日以外は現在時刻の印を出さない
