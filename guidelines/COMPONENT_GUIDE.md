# COMPONENT_GUIDE — どの部品を使うか、状態をどう設計するか

> 答える問い: **似た部品のどれを選ぶか。ローディング・空・エラー・完了をどう見せるか。**
> 部品ごとの組み方は `components/` の各仕様書。一覧は `components/component-index.md`。

## 1. 混同しやすい部品の使い分け

### 1.1 ボタンの種類

| やりたいこと | 部品 | 1画面の上限 |
|---|---|---|
| その画面で一番してほしい操作（申し込む・読み取る・次へ） | ボタン primary（橙） | 1つ |
| 二番目の操作、別ページへの主要な移動 | ボタン secondary（青） | 2つまで |
| 戻る・キャンセル・補助的な操作 | ボタン ghost（白＋青枠） | 制限なし |
| カード全体を1つの操作にしたい（画面の主役） | カード型ボタン（`card.md` §3） | 1つ |
| 文中の移動・外部サイト | テキストリンク | 制限なし |

- 同じ操作を2つのボタンで並べない
- 「詳しく見る」「こちら」ではなく、行き先や結果が分かるラベルにする（`WRITING_GUIDE.md` §3）

### 1.2 一覧の見せ方

| 中身 | 部品 |
|---|---|
| 名前・場所・時間など文字が中心で、件数が多い | リスト行（`list-item.md`）を白い帯に並べ、場所コードの見出しで区切る |
| 時刻×場所のように2つの軸で読む | 表（`layout_patterns/timetable.html`）。カードを格子に並べない |
| 画像が主役（チラシ・写真） | カード一覧（2列は768px以上）。写真がない件は文字の行にする |
| いま開催中・次に始まる | サイン板（FOUNDATIONS §5.2）の中にリスト行。開催中の件に `now-marker.md` の印 |
| 画像を1枚ずつ大きく見せ、横にめくる | 横スクロールのカルーセル（`carousel.md`） |
| 絞り込みの条件 | チップの横並び（`chip.md`） |

### 1.3 お知らせの種類

| 伝える内容 | 部品 | 消え方 |
|---|---|---|
| 操作の結果（保存した・コピーした） | トースト | 自動で消える |
| 画面全体に関わる注意（保存できない・通信できない） | 通知バー（`notice.md`） | 閉じるボタンか、原因が解消したら |
| 入力の誤り | 入力欄の直下のエラー文 | 直したら消える |
| 確認が必要な操作（消す・やり直す） | 確認ダイアログ（`dialog.md`） | ユーザーが選ぶまで |
| 補足・ヒント・拡大表示 | 小窓ダイアログ | 閉じるボタン |

### 1.4 開閉する部品
- 1画面の中で補足を折りたたむ → アコーディオン（`<details>`、`accordion.md`）
- 画面を離れずに別の内容を重ねる → ダイアログ（`<dialog>`）
- 主な流れ（申し込み手順など）をダイアログに入れない。ページを分ける

## 2. 状態設計

すべてのデータ表示・操作で、次の状態を用意する。作らない状態は理由をページの判断（`pages/`）に書く。

| 状態 | 見せ方 | 置き場所 |
|---|---|---|
| 通常 | — | — |
| 読み込み中 | 300ms を超えるなら、最終的な形と同じ大きさのスケルトン（`bg-surface-soft` の面）。ボタンは文言を「〜中」にして `disabled` | 読み込む領域そのもの |
| 空 | なぜ空か＋次にできること（1文＋操作1つ）。アイコンは `icon.empty` | 一覧があるはずの場所 |
| エラー | 何が起きたか＋どうすればよいか＋再試行ボタン。文は `text-danger`、枠は `border-danger` | 失敗した操作のすぐ近く |
| 完了 | 結果を1文で。次の操作を1つ（primary） | 画面中央か、操作したボタンの近く |
| 無効 | 不透明度 0.45。押せない理由が分かる文を近くに置く | — |

- 権限の拒否（カメラ・位置情報）は「許可されていない」ことと「代わりの方法」（コード入力など）を並べて出す
- 通信できないときも、すでに表示している内容は消さない

## 3. 操作の状態

| 状態 | 表し方 |
|---|---|
| hover（マウスのみ） | 塗りボタンは押下色へ、枠線ボタンは `bg-surface-soft`。`@media (hover: hover)` の中だけで書く。文字を薄くしない |
| 押下 | `scale.press` に縮小、塗りは押下色 |
| フォーカス | `focus-ring` 3px・offset 3px |
| 選択中 | 色＋太字＋形（ピル・下線）。`aria-current` / `aria-pressed` / `aria-selected` を付ける |
| 無効 | 不透明度 0.45、`cursor: default` |

## 4. 共通にする部品・しない部品

- `components/base/`: どのページでも使う部品
- `components/specific/`: 来場者企画だけの部品。ほかのページで使う前に、そのページの判断として理由を書く
- 新しい部品が2ページ以上で必要になったら、`review/FINDINGS.md` に提案してから `base/` に追加する
