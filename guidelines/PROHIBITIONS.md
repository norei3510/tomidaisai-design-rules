# PROHIBITIONS — 禁則

> 答える問い: **生成・レビューのとき、何をしてはいけないか。**
> 各項目は根拠になるガイドを指す。新しい禁則は `review/FINDINGS.md` で提案し、承認後に追加する。
> 禁則を増やしすぎない。ほかのガイドで表せることはそちらに書く。

## 色
1. `#F26A00`（`graphic-accent`）の上に白文字を載せない。橙の塗りは `action-primary` → FOUNDATIONS §2.2
2. `text-secondary` を水色の下地に置かない → FOUNDATIONS §2.2
3. `graphic-main`（`#2082C3`）を文字色にしない → FOUNDATIONS §2.2
4. 橙の主要ボタンを1画面に2つ以上置かない → COMPONENT_GUIDE §1.1
5. 色だけで状態を伝えない → FOUNDATIONS §2.2
6. 16進カラーを直書きしない（画像・素材の中は例外） → TOKEN_GUIDE §3
7. 紫のグラデーション、ベージュ・クリーム色の下地、全面のグラデーションを使わない

## 文字
8. 12px未満の文字を使わない → FOUNDATIONS §3
9. 決めた3書体（見出し・数字・本文）以外を当日ページに使わない。見出し用の書体を小さい文字や長い文に使わない（来場者企画の物語演出は例外） → FOUNDATIONS §3.1
10. ボタン・ナビ・チップのラベルを省略記号で切らない → WRITING_GUIDE §3

## 余白・形
11. トークンにない余白・角丸・影を作らない → TOKEN_GUIDE §3
12. 白いカードの中に白いカードを入れない → PAGE_LAYOUT_GUIDE §2
13. 色付きの左ボーダーをつけた角丸カードを注意書きに使わない（通知バーを使う）

## 操作
14. 44px未満の押せる要素を作らない → FOUNDATIONS §9
15. hover で文字を薄く・灰色にしない → COMPONENT_GUIDE §3
16. フォーカス枠を消さない（`outline: none` だけで終えない） → FOUNDATIONS §9
17. ボトムナビを装飾だけのタブにしない（リンクを持つ `nav` にする） → components/base/bottom-nav.md
18. 主な流れをモーダルの中に入れない → COMPONENT_GUIDE §1.4

## 内容
19. 実在しない数字・実績・企画情報を作らない → WRITING_GUIDE §5
20. 見出しごとにアイコンを付けない。絵文字を機能アイコンにしない → FOUNDATIONS §6
21. 手描き風のSVGの人物・風景を飾りに使わない
22. 謎解きの問題・答え・物語の内容を共通ページや本リポジトリに載せない
23. 内容を伝える画像（チラシ・写真・地図）を切り抜き・変形しない。比率を保って全体を見せる

## AIっぽさ（当日ページ） → FOUNDATIONS §1.2
24. 同じ大きさの白い角丸カード＋やわらかい影（`shadow-1`）を並べて一覧・見出しまわりを作らない。罫線と白い帯で組む → FOUNDATIONS §5.1
25. 英字アイブロウ（「EVENTS」など）＋h1＋1行説明の定型の見出しを作らない。英字は場所コードと時刻にだけ使う → PAGE_LAYOUT_GUIDE §2
26. 最大の文字を 22px 前後の見出しにしない。h1 は `3xl` 以上、主役の数字は `4xl`〜`5xl` → FOUNDATIONS §3.2
27. サイン板（青い見出しの帯＋青の外枠）を1画面に2つ以上使わない。当日ページでダイアログ以外に影を使わない（ずらし影・やわらかい影とも） → FOUNDATIONS §5.2・§5.3
28. 橙を「いま・ここ・押す」以外（見出しの飾り線・分類の色分け・背景の飾り）に使わない → FOUNDATIONS §2.1
29. 紹介文・キャッチコピー・ヒーロー画像でコンテンツの前置きをしない。最初の画面にコンテンツそのもの（時刻・一覧・表・地図）を出す → PAGE_LAYOUT_GUIDE §6
30. 「さまざまな企画を楽しもう！」のような、どの祭りにも当てはまる文を書かない → WRITING_GUIDE §5
31. ストック写真・AI生成画像を使わない。写真は団体・実行委員会が提供した実物だけ。ない企画は文字だけで見せる
32. グラデーション・すりガラス風（`backdrop-filter`）・光彩・装飾だけの図形を使わない
