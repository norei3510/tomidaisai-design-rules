# WRITING_GUIDE — どう書くか（文体・用字用語）

> 答える問い: **画面に出す文をどう書くか。言葉をどう統一するか。**
> 来場者企画の物語・セリフは本書の対象外（トミー君の口調は企画側で管理する）。

## 1. 文体

- です・ます調。短く、1文1つの内容
- 来場者に話しかける。「〜してください」より「〜できます」「〜しましょう」を優先する（禁止・注意の文は「〜してください」でよい）
- 句読点は「、」「。」。来場者企画の一部コードにある「, .」は使わない
- 感嘆符は完了・成功の表示だけ、1画面1つまで

## 2. 用字用語

| 使う | 使わない | 備考 |
|---|---|---|
| 富大祭 | — | 正式名称が必要な場所は実行委員会の表記に従う |
| 来場者企画 | ビジター企画、VP | ナビの表示名 |
| 企画 | イベント、出し物 | ナビの表示名 |
| ステージ | タイムテーブル（ナビ名として） | ページ内の時刻表は「タイムテーブル」でよい |
| マップ | 地図、MAP | ナビの表示名 |
| TOP | トップ、ホーム | ナビの表示名のみ。文中は「トップページ」 |
| 出展 | 出店、ブース | 【暫定】来場者企画の表記 |
| QRコード | QR、二次元コード | ボタン名は「QRコードを読み取る」 |
| 読み取る | スキャンする、読み込む | |
| ログイン、アカウント | — | 現状は使わない（認証なし） |

- 数字は半角。時刻は「10:00〜12:00」（全角の波ダッシュ）、日付は「M月D日（曜）」の形【暫定】
- 建物・教室の名前は大学の表記に合わせる。略さない
- 英字の小見出し（アイブロウ）は当日ページでは使わない（来場者企画は大文字で、日本語の見出しと同じ意味にする）
- 場所コードは半角英数字で、看板・地図と同じ表記にする（例: 「A」「B2」）。コードの後ろに正式な建物名を必ず添える

## 3. ラベル

| 種類 | 書き方 | 例 |
|---|---|---|
| ボタン | 動詞で終える。結果が分かる。8文字前後まで | 「QRコードを読み取る」「マップで見る」「次へ」 |
| ナビ | 名詞。2〜5文字 | 「企画」「マップ」 |
| チップ | 名詞。4文字まで | 「飲食」「展示」 |
| リンク | 行き先の名前 | 「ステージの時間を見る」（「こちら」「詳しくは」にしない） |
| 入力欄 | 何を入れるかを名詞で。例は欄の下に補足として | ラベル「場所コード」＋補足「看板に書かれた英数字」 |

- ラベルは折り返さない長さにする。収まらないときは文を短くするか部品を変える（省略記号で切らない）
- 企画名・場所名などデータの文字は、一覧では1行で省略してよい。詳細ページでは全文を出す

## 4. エラー・空・確認の文

| 種類 | 型 | 例 |
|---|---|---|
| エラー | 何が起きたか。どうすればよいか。 | 「このQRコードは使えません。会場の案内用QRコードを読み取ってください。」 |
| 空 | なぜないか。次にできること。 | 「この条件の企画はありません。条件を減らしてください。」 |
| 確認 | 何が起きるかを質問の形で。ボタンは動詞 | 「すべての進捗を消して、最初から始めますか？」［消して始める］［やめる］ |
| 完了 | 何が終わったか | 「保存しました」 |

- 「無効な入力です」「エラーが発生しました」だけで終えない
- 来場者のせいにしない（「入力が間違っています」→「英数字6文字で入力してください」）

## 5. 書かないこと

- 実在しない数字・実績・宣伝文句。未確定の情報は「準備中」と明記したプレースホルダにする
- 開発用の文言・コード・内部名（画面に出る前に消す）
- どの祭りにも当てはまる文（「さまざまな企画を楽しもう！」「富大祭をもっと楽しく」）。代わりに件数・時刻・場所など、このページでしか言えない値を書く
- ページの使い方の説明（「キーワード・種類・会場・日付で探せます」）。操作の部品を見れば分かることは書かない
