# 企画一覧（/2026/events/）

> 正: 共通ルール（`guidelines/`・`components/`・`tokens/`）。本ファイルはこのページの選択だけを記録する（共通ルールは再掲しない）。
> 本ファイルに無い項目は共通ルールに従う。`（要確認）` は生成前に人が確定する。
> 実装: tomidaisai2026 `front/src/main.js`（`eventsMarkup` ほか）・`front/src/events.css`。tokens は v0.3.0 を `front/src/design-tokens.css` に固定。書体は Adobe Fonts の当日ページ用キット `bqk8omc`（`front/index.html`）。

## 目的
- 誰が・いつ・何のために見るか: 来場者が当日、会場を歩きながら、行きたい企画を探す
- 最初の画面で分かること: ページ名（企画一覧、中央揃え）、探すための入力欄と絞り込み。件数は一覧の上の1か所だけに出す（2026-10-22 の依頼で h1 下の「全86件・日付」の行を外した）
- 主な操作（primary）: なし。一覧の行から詳細へ移動する（橙の主要ボタンを置かない）

## 骨格
- 使う骨格: list（`layout_patterns/layout-index.md`）
- 骨格と違う点:
  - 絞り込みの前にキーワードの入力欄を置き、入力欄と絞り込みを白い帯1枚にまとめた
  - 共通ヘッダー（ロゴ `front/assets/brand/logo-2026.png`、756×228）とボトムナビ（「企画」が選択中）を置いた（2026-10-22 の依頼）。ヘッダーは上に固定（sticky）、ナビは下に固定し、本文の下にナビの高さぶんの余白をとる
  - ヘッダー・ナビは企画一覧・企画詳細・タイムテーブルにある（外枠は tomidaisai2026 `front/src/shell.css`）。TOP・マップは旧デザインのまま

## 使う部品
| 部品 | 使い方 | 共通ルールとの違い |
|---|---|---|
| 入力欄 | キーワード検索。枠の中に虫めがね＋プレースホルダ「キーワードを入力」 | 見えるラベルと補足を置かない（下記） |
| フィルターチップ | 種類・日付。複数選択、「すべて」で解除 | なし |
| フィルターチップ（会場） | 屋内／メインストリート／メインステージ／黒田講堂。種類・日付と同じ方式 | 下記「会場もチップにした」 |
| 区切りの見出し | 会場名（display `bold` `xl`）＋件数（numeral）＋紺の2px罫線 | 場所コードの札はまだ出さない（下記） |
| リスト行 | 開始時刻のある企画だけ左端に時刻（numeral）。名前／団体名／種類・日付・場所 | 補足を2行にした（下記） |
| 開催中の印 | 開催中の企画の右端に、矢印の代わりに出す（now-marker.md §1） | なし |
| ボタン ghost | 「条件を解除する」 | なし |
| 共通ヘッダー | 富大祭2026のロゴ。押すと TOP へ | クラス名は旧 CSS の `.site-header` とぶつからないよう `ev-header` |
| ボトムナビ | 5項目、「企画」が選択中。選択中の項目を押すとページの先頭へ戻る | クラス名は `ev-nav` |

## 状態
| 状態 | 見せ方 |
|---|---|
| 読み込み中 | 区切りの見出しとリスト行と同じ形のスケルトン6行。入力欄・チップは無効 |
| 空 | 「この条件の企画はありません。」「条件を減らしてください。」＋［条件を解除する］。一覧の上の解除ボタンは隠す（同じ操作を2つ並べない） |
| エラー | 「企画情報を読み込めませんでした。」＋［もう一度読み込む］（secondary） |

## このページだけの判断
| 判断 | 理由 | 共通ルールへの昇格候補 |
|---|---|---|
| 会場もチップにした（「メインストリート」など4文字を超えるラベルを含む） | 種類・日付と同じ操作にそろえる依頼（2026-10-22）。chip.md のラベル上限（4文字）を超えるが、建物名は略さない（WRITING_GUIDE §2） | はい（chip.md の上限を見直す候補） |
| キーワード欄に見えるラベル・補足を置かず、虫めがねとプレースホルダだけにした。読み上げ用のラベル「キーワードで探す」は残す | 依頼（2026-10-22）。text-field.md の「ラベルを常に表示」と違う。検索欄は虫めがねで用途が分かり、入力欄が1つだけのため | はい（検索欄だけの例外として text-field.md に足す候補） |
| チップは横スクロールにせず、幅に収まらなければ次の行へ折り返す | 隠れたチップに気づかないため。依頼（2026-10-22） | はい（chip.md の並べ方の候補） |
| 一覧を4つの会場（屋内／メインストリート／メインステージ／黒田講堂）で区切った。会場が複数ある企画は最初の会場（会場で絞り込んでいるときは選んだ会場）にだけ出す | 場所コードが未定のため、絞り込みと同じ会場の分け方を使った。同じ企画を2回並べないため | いいえ（場所コードが決まったら場所コードで区切り直す） |
| 区切りの見出しに場所コードの札を出していない | コードの割り当てが未定。看板と違うコードを来場者に見せないため | いいえ |
| 時刻のある企画を開始順に、そのあとに時刻のない企画を並べた。時刻のない企画には「終日」も出さない | 時刻を見て選ぶ人と、場所で選ぶ人の両方に合わせるため。屋内の企画の多くは開始時刻がなく、「終日」は不要との依頼（2026-10-22） | いいえ |
| 開催中の印は、開始・終了時刻のある日程にだけ出す | 終日の企画は開場時間が未定で、開催中かどうか判断できない | いいえ |
| 確認用に `?now=2026-10-24T13:40` で時刻を指定できる。画面には操作を出さない | 開催日前でも開催中の印と橙を確かめるため | いいえ |
| リスト行の補足を2行（団体名／種類・日付・場所）にした | 一覧で団体名と場所の両方を見て選ぶため。list-item.md の補足は1行 | はい |
| 種類はタグにせず、補足の文字にした | 橙の分類タグは v0.3.0 の PROHIBITIONS 28 に当たる。行の情報量を増やさないため | いいえ |
| 日付チップは「10/24」表記、読み上げは「10月24日（土）」 | チップは4文字前後に収めたい。WRITING_GUIDE の日付形式【暫定】は読み上げ側で満たす | いいえ |
| 写真が読み込めない企画は、サムネイルの枠を消して文字だけの行にする | list-item.md「写真がない件に空の枠を出さない」に合わせる | いいえ |
| 768px以上は、会場の区切りを2列に並べる | 骨格 list.html と同じ形。屋内が長いので左の列が長くなる | いいえ |
