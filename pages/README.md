# pages — ページごとの判断

> 答える問い: **このページだけで、なぜこう決めたか。**
> 共通ルールから外れたこと・共通ルールにないことを、ページごとに1ファイルで残す。共通ルールは再掲しない。

- ファイル名: `pages/<ページのパス>.md`（例: `pages/2026-events.md`）
- ひな形: `_template.md`
- 2ページ以上で同じ判断をしたら、`review/FINDINGS.md` に昇格を提案する
