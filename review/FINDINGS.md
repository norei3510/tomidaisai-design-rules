# FINDINGS — レビューで見つけたことを共通ルールへ戻す

> 答える問い: **レビューの気づきを、どこに、どう反映するか。**
> 画面を直すことと、共通ルールを直すことは分ける。共通ルールへの反映は人が承認してから行う。

## 流れ

1. **記録**: 下の表に1行追加する（状態は「提案」）
2. **戻し先を決める**: 次のどれに関わるかを書く
   - 値 → `tokens/*.json`
   - 判断・原則 → `guidelines/*.md`
   - 部品の組み方 → `components/**/*.md`
   - 骨格 → `layout_patterns/`
   - その画面だけ → `pages/<ページ名>.md`（共通ルールにしない）
3. **提案**: 昇格（ページの判断 → 共通ルール）、変更、降格（共通ルール → ページの判断）のどれかを書く
4. **承認**: 人が確認して状態を「承認」か「見送り」にする
5. **反映**: 戻し先のファイルを直し、`CHANGELOG.md` に書き、状態を「反映済み」にする
