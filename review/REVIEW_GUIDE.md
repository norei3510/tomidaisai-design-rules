# REVIEW_GUIDE — 作った画面をどう確かめるか

> 答える問い: **できた画面を、どの観点で、何を基準に確かめるか。**
> 観点ごとに読むファイルを絞る。全部を毎回読まない。

## 1. 観点と読むもの

| 観点 | 読むもの | 主な確認 |
|---|---|---|
| 部品 | FOUNDATIONS・PROHIBITIONS・COMPONENT_GUIDE・TOKEN_GUIDE・使った部品の仕様書 | 部品の選び方、状態、トークンの使い方 |
| レイアウト | PAGE_LAYOUT_GUIDE・layout-index | 骨格、並び順、画面幅ごとの組み替え |
| 文言 | WRITING_GUIDE | 文体、用字用語、ラベル、エラー文 |
| アクセシビリティ | FOUNDATIONS §2.2・§9 | コントラスト、44px、フォーカス、色だけに頼らない |

## 2. チェックリスト

### 部品・トークン
- [ ] 色は semantic 変数だけ。16進カラーの直書きがない
- [ ] 余白・角丸・影・文字サイズがトークンの値だけ
- [ ] primary ボタンは1画面に1つ
- [ ] 読み込み中・空・エラー・完了の状態がある（作らないなら理由が `pages/` にある）
- [ ] ボトムナビがリンクを持つ `nav` で、選択中に `aria-current="page"`

### レイアウト
- [ ] h1 が1つ、最初の画面で「いまどこか」「次に何をするか」が分かる
- [ ] 375px で横スクロールが出ない。768px 以上で一覧が2列
- [ ] 最後の要素がボトムナビに隠れない。セーフエリアを考慮している
- [ ] 内容を伝える画像が切り抜き・変形されていない

### 文言
- [ ] です・ます調、「、」「。」
- [ ] ボタンのラベルが動詞で終わり、1行に収まる
- [ ] エラー文に原因と直し方がある
- [ ] 実在しない数字・情報がない（未確定は「準備中」）

### アクセシビリティ
- [ ] 本文 4.5:1、大きい文字・アイコン・枠 3:1
- [ ] `text-secondary` が水色の下地に置かれていない
- [ ] 押せる要素が 44px 以上、間 8px 以上
- [ ] キーボードで全操作に届き、フォーカス枠が見える
- [ ] 動きを減らす設定で動きが止まる

## 3. 見つけたことの扱い
- その画面だけの直し → 画面を直す。判断を `pages/<ページ名>.md` に残す
- 共通ルールに関わる気づき → `FINDINGS.md` に記録する（次節の流れ）
