# 基本ルール

## 配色

| 役割 | トークン | 値 |
|---|---|---|
| 背景 | --bg | #C8E7FF |
| ブランドの青 | --main | #2082C3 |
| 青い背景・操作色 | --main-dark | #18679D |
| 青の押下状態 | --main-pressed | #125580 |
| ブランドのオレンジ | --accent | #F26A00 |
| オレンジの文字・主要操作色 | --accent-text | #B34A00 |
| オレンジの濃色状態 | --accent-dark | #903C00 |
| 本文 | --ink | #173A52 |
| 補足文 | --muted | #5B7A93 |
| エラー | --danger | #D93636 |

白いカードを基本とし、オレンジは主要操作や強調に使います。背景色と操作色は用途で区別します。色だけで選択・エラーを伝えず、文字・形・状態属性も使います。

## 文字

本文書体はNoto Sans JP、利用できない場合はCSSのシステムフォントへ切り替えます。本リポジトリにはフォント本体を含めません。

サイズは12・14・16・18・22・26・34px、本文行間は1.7、見出し行間は1.3です。本文は16px、通常400、強調700を基本とします。ゲーム内のセリフ用書体は共通仕様に含めません。

## 余白・形・影

余白は4・8・12・16・20・24・32pxです。角丸はカード14px、入力10px、チップ8px、モーダル20px、ピル999pxです。影は `--shadow-1` と `--shadow-2` を使います。値の正本はCSSトークンです。

## 操作状態

1. 通常・押下・選択・無効・フォーカスを区別します。
2. キーボードのフォーカスを可視化し、選択中のナビには `aria-current="page"` を使います。
3. 主要ボタンの操作領域は48pxを基準とし、隣接操作との間に余白を設けます。
4. 読み込み中・失敗・再試行を、操作対象の近くで伝えます。
5. 動きを減らす設定では、装飾的な画面遷移を抑えます。

## レイアウトとセーフエリア

四辺の `env(safe-area-inset-*)` を考慮します。ヘッダーやナビに隠れる領域を本文の高さに含めず、入力時も必要な操作に到達できる状態を保ちます。

来場者企画の最大幅390px・ゲーム画面のスクロール制限はゲーム固有です。当日サイト全体の幅やスクロール制限としては適用しません。PC・スマートフォン双方で内容に合わせてレイアウトします。
