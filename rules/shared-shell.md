# 共通ヘッダーとボトムナビ

本書は後続実装のための共通仕様です。部品コードはこのリポジトリに含めません。

## ヘッダー

1. 外側の枠・背景・高さ・余白・セーフエリア処理を共通化します。
2. 左側は通常の富大祭ロゴを標準とし、来場者企画だけ専用ロゴに差し替えます。画像は利用側が渡します。
3. 右側はページごとの要素を渡せる領域にします。検索・日付・進捗などの処理を共通枠へ持ち込みません。
4. 参照元の現行実装は高さ67px＋上セーフエリア、背景 `--main-dark` です。ボトムナビ作り直し時の基準値であり、新デザインが指定された場合は更新します。

## ナビの構成

| 表示名 | リンク先 | 選択対象 |
|---|---|---|
| TOP | /2026/ | TOP |
| ステージ | /2026/stage/ | ステージと互換タイムテーブルURL |
| 企画 | /2026/events/ | 一覧と企画詳細 |
| 来場者企画 | /3190/ | 来場者企画の全画面 |
| マップ | /2026/map/ | マップ |

リンクはドメイン直下からのパスにします。来場者企画との移動は通常のページ遷移です。両アプリの内部ルーターを共有しません。

参照元の現行実装は高さ60px＋下セーフエリア、白背景、選択色 `--accent-text` です。作り直す際は実際のリンクを持つ `nav` とし、装飾だけのタブとして実装しません。

## 共有方法

作り直し時に、フレームワークをまたいで利用できる共通部品として実装し、両サイトで同じ版を使います。利用側から渡す要素は、現在のタブ、通常／専用ロゴ、ヘッダー右側の内容です。

今回は当日サイト・来場者企画ともに部品の差し替えを行いません。部品の配布方式は、その実装作業で確定します。
